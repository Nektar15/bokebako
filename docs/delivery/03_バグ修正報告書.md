## 2. 各不具合

### N-01 Vercel の DB（P0・仮置き環境）

- 再現：Vercel で開催した直後の URL に同時に 40 件 → 200 が 11 件、404 が 29 件。約 10 分後には全件 404
- 原因：`api/index.php` が SQLite を `/tmp` に置く（ADR 0008）。Vercel はインスタンスごとに `/tmp` が別
- 修正：外部の MySQL 互換 DB を使えるようにした。インスタンスごとに 1 回 `vercel:prepare`（マイグレーション、空のときだけ開発用データ）。TLS 必須の DB 用に `database.default.sslCA`
- ファイル：`api/index.php`、`app/Commands/VercelPrepare.php`、`app/Config/Database.php`、`.env.example`、`docs/vercel.md`
- 再発防止：`docs/vercel.md` の表に「SQLite のままだと同時アクセスの多くが 404」を明記。確かめ方（同時に何十件か送る）も書いた
- テスト：`vercel:prepare` を空の DB に 2 回流し、1 回目だけ開発用データが入ることを確認（ローカル、SQLite）。**外部 DB・Vercel 上では未確認**
- 残り：発注者が DB のアカウントを作り、Vercel の環境変数を設定して Redeploy する

### BUG-001 X のカード

- 原因：① N-01（クローラーが 404 を受け取る）② トップに OGP がない ③ 回答のページの説明文が募集の文言
- 修正：レイアウトで全ページに `og:site_name`・`og:locale`・`og:type`・`og:image:width/height`。`og:image` のないページは既定のカード。回答のページの `og:description` を回答の中身に
- ファイル：`app/Views/layouts/front.php`、`app/Views/front/u04_answer.php`
- テスト：`tests/Feature/OgpMetaTest.php`（5 画面で必要なタグ、JS なしの HTML）、E2E `main-flow`（回答のページの説明文）
- 残り：X 上の実表示（データの消えない環境で投稿して確認）

### BUG-002 合言葉で開催できない

- 再現：合言葉に `abc`（3 文字）→ 何も出ずにトップに戻る。前後に全角スペースを付けた合言葉 → 別の端末で同じものを入れても「合言葉が違います」
- 原因：① U-01 に合言葉のエラーを出す場所がなかった ② 開催時は `Text::clean()`、本人確認時は `trim()` で整えていた
- 修正：U-01 に欄のエラーを出す。整え方を `App\Libraries\Passphrase` にまとめ、開催時と本人確認時で同じにした（前後の空白・見えない文字を取り NFKC）。保存は SHA-256 → bcrypt。以前の形式も照合できる
- ファイル：`app/Libraries/Passphrase.php`、`app/Services/OogiriService.php`、`app/Services/HostService.php`、`app/Views/front/u01_top.php`、`app/Views/host/u08_recover.php`
- テスト：`tests/Feature/PassphraseTest.php`（必須、4/32 文字の境界、全角スペース・全角英数・見えない文字・記号・32 文字の日本語、72 バイトで切られない、以前の形式、平文で保存しない、U-01 にエラーが出る）、E2E `errors`・`main-flow`

### BUG-003 スマホの募集ボタン

- 確認：iPhone 13・Pixel 7 の画面（Chromium）では U-03 にボタンが出ていた（CSS の問題はなかった）
- 原因：① N-01 で U-03 が開けない ② 別の端末・X のアプリ内のブラウザで開くと、開催者と分からず、ボタンのない U-04 に回される
- 修正：X のボタンの下に「ほかのアプリで共有」（Web Share API が使える端末だけ）。開催者本人が募集 URL（U-04）を開いても募集のシェアを出す
- ファイル：`app/Views/partials/share_buttons.php`、`public/assets/js/components/web-share.js`、`app/Controllers/Front/RendersAnswerPage.php`、`app/Views/front/u04_answer.php` ほか
- テスト：E2E `ui`（共有シートの有無、送り終えたらトースト、開催者の U-04、幅 320px で収まる）
- 残り：iPhone Safari・Android Chrome の実機
