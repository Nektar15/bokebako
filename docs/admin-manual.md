# 管理画面マニュアル

運営担当者向け。管理画面は `https://<ドメイン>/<admin パス>`（パスは `.env` の `app.adminPath`。既定は `/admin`）。
ID（またはメールアドレス）とパスワードでログインする。二段階認証（TOTP）は未実装（最終工程で追加する）。

## A-01 ログインと管理者アカウント

- 5回続けてパスワードを間違えると、そのアカウントは15分ログインできない。同じ場所（IP）からの試行が多すぎるときも、しばらく止まる
- 2時間操作しないか、ログインから12時間たつと、ログインし直しになる。終わったら左下の「ログアウト」
- 最初の上位管理者はサーバーで `php spark admin:create <ID> <表示名>` を実行して作る（README）
- **管理者アカウント**（左メニューの最後）：上位管理者は管理者の追加、名前・権限の変更、パスワードの再設定（一時ロックも解ける）、削除ができる。自分の権限変更・自分の削除・上位管理者を0人にする操作はできない。一般管理者は自分のパスワード変更だけ
- パスワードを変えると、ほかの端末のログインは切れる。パスワードを忘れたら、上位管理者に再設定してもらう（上位管理者が1人で忘れたら、サーバーで `admin:create` を使って新しい上位管理者を作る）
- 管理画面を特定の IP からだけ開けるようにするには、`.env` の `ADMIN_ALLOWED_IPS` に IP を入れる（ログイン画面も含めて、それ以外は 403）

権限は2種類。**上位管理者**はすべての操作ができ、**一般管理者**は A-04 の「投稿元」列（IP・ブラウザIDのハッシュ）が見えない。

## 毎日やること

1. **A-02 ダッシュボード**で前日の数字を見る。右の「対応が必要なもの」に件数が出ていたら、そこから各画面へ
2. **A-05 通報・モデレーション**の待ち行列を上から処理する（並びは優先度順：通報急増 → 通報件数 → NG検知 → 異常投稿 → AI「要確認」）
3. **A-09 お問い合わせ**の「未対応」に返信し、状態を進める

自動処理（cron）が止まっていると、募集が終わらない・結果未選出にならない・AI判定が進まない。A-02 の「開催数（日別）」が前日で止まっていたら、サーバーの cron を疑う（README「cron」）。

## A-02 ダッシュボード

- 期間：今日／昨日／7日／30日／期間指定。「今日」は**前日分までの集計**（毎日 4:00 の日次バッチ）。リアルタイムではない
- 最重要 KPI：**回答者→開催者 転換率**（回答したブラウザのうち、その後に開催したブラウザの割合）と**派生開催係数**（開催数に対する、参加者から生まれた新規開催の比率。1.0 を超えると自力で広がっている）
- 「対応が必要なもの」：モデレーション待ち、NGワード「要確認」、未対応のお問い合わせ、AI 未判定の件数

## A-03 大喜利管理

- 一覧：状態タブ（すべて／募集中／結果選択待ち／確定／結果未選出／非表示／削除済み）、検索（お題・ID・スラッグ）、期間、並び替え（新着・PV・回答数・派生開催数・通報数）
- 行の操作：**非表示**（公開ページが U-13「公開されていません」になる。元の状態は覚えておき、再公開で戻る。締切後に再公開すると結果選択待ちになり、選出期限も過ぎていれば1分以内に結果未選出になる）、**再公開**、**削除**（論理削除。復元は DB 操作が要るので、迷ったら非表示）
- 非表示・削除すると、その大喜利の OGP 画像（募集・結果・回答シェア用）もサーバーから消える。再公開で募集・結果の画像は作り直す。ただし Cloudflare などの CDN はキャッシュが切れるまで古い画像を配信し、X など SNS 側に取り込まれた画像は消せない
- 詳細：回答の一覧（非表示・削除済みも含む）、ベスト回答、操作履歴
  - **代理でベスト回答を変更**：開催者が誤って確定したときに使う。「順位を変更する」→ 1位〜3位の回答 ID を選ぶ（1件以上）。確定済みでなくても確定扱いになるので注意。選べるのはこの大喜利の公開中の回答だけで、1件でも合わなければ何も保存されない。非表示・削除中の大喜利は、再公開してから変える
  - **ページキャッシュを再生成**：結果ページの表示が古いとき。捨てて次のアクセスで作り直す

## A-04 回答管理

- 大喜利をまたいで回答を探す：本文、お題（お題の文言・ID・スラッグ）、状態、通報件数（1件以上／3件以上）、期間
- 操作：非表示／再公開／削除。非表示・削除すると回答数とベスト回答（順位）から外れ、結果ページのキャッシュが捨てられる。その回答のシェア用 OGP 画像は消え、結果画像は今の公開状態で作り直す
- 「投稿元」列（上位管理者のみ）：同じ投稿元からの連続投稿を見分けるためのもの。値はハッシュで、個人の特定には使えない

## A-05 通報・モデレーション

待ち行列には、**通報された投稿**、**NGワード「要確認」に当たった投稿**、**短時間に連続投稿された投稿（異常投稿）**が入る。AI 補助判定が有効なら、各行に AI の判定（問題なし／要確認／非表示）と理由が付く。

- 絞り込み：すべて／通報／NG検知／異常投稿／AI要確認。行をクリックすると右に詳細（本文、通報の理由と件数、検知内容、操作履歴）
- 操作（右の詳細で）：
  - **問題なし**：待ち行列から外す（公開状態は変えない。通報で自動非表示になっていた投稿を戻すときは、A-03／A-04 の「再公開」を別途行う）
  - **非表示**：公開ページから消す（元に戻せる）
  - **削除**：論理削除
  - **投稿元を制限**：その投稿のブラウザ・IP からの投稿を 1時間／24時間／7日間 止める
- 自動で非表示になる条件（A-10 で変更）：同じ投稿に、別々のブラウザから `report_count` 件の通報が `report_window_min` 分以内に入ったとき。通知メールが届く

## A-06 NGワード管理

- ワード、一致方式（部分一致／完全一致／正規表現）、カテゴリー、処理（**投稿拒否**＝投稿させない／**要確認**＝投稿は通して A-05 に積む）、有効
- 「ためしに判定」で、登録前に文章を当ててみられる
- CSV：エクスポートした形式（`word,match_type,category,action,enabled`）でインポートできる。同じワード・一致方式の行は上書き
- 変更は即座に反映される（判定用のキャッシュをその場で捨てる）

## A-07 広告管理

- 登録：名前、スポンサー、画像（表示 320×50。640×100 の2倍サイズを推奨。`public/assets/ads/` に保存）、リンク先（https のみ）、掲載場所（上部／下部）、掲載期間、状態（下書き／公開／停止）
- 表示回数とクリック数、CTR は自動で集計される。一覧の「配信中」は公開かつ期間内のもの
- 期間が過ぎた広告は自動で出なくなる。削除は物理削除（画像も消える）

## A-08 OGP 管理

X でシェアされたときの画像（募集用・結果用・回答用）。通常は自動で作られる。

- **個別に再生成**：種類と対象（大喜利の URL・スラッグ・ID、回答は `A-{回答ID}`）を指定。お題を直した後や、画像が壊れていたとき
- **背景・ロゴの差し替え**：PNG をアップロードすると `writable/ogp-templates/` に置かれ、以後の生成に使われる。既存の画像は再生成しないと変わらない
- 最近の生成記録に「失敗」が並ぶときは、サーバーにフォントがない（README「OGP 画像」）

## A-09 お問い合わせ管理

- 種類（削除依頼／権利侵害／広告掲載／その他）と状態（未対応／対応中／完了）で絞り込み
- 行をクリックして状態の変更と対応メモ。メモは履歴として残る（消せない）
- 返信は管理画面から送れない。メールソフトで返信し、その旨をメモに残す

## A-10 運用設定

保存すると次のアクセスから反映される。値の範囲外はエラーになる。

| 項目 | 意味 | 既定 |
|---|---|---|
| お題・回答の最大文字数 | 入力欄の上限 | 100 / 140 |
| 募集時間 | 開催から募集終了までの時間 | 24 時間 |
| 結果選出の期限 | 募集終了から、開催者がベスト回答を選べる時間。過ぎると「結果未選出」で確定 | 72 時間 |
| 連続投稿の判定 | 同じ環境から N 回／M 秒を超えたら制限 | 3 回／60 秒 |
| 制限の方法 | 一時的に止める／CAPTCHA を出す／一定時間投稿停止 | 一時的 |
| 通報による非表示 | 別々の環境から N 件／M 分で自動非表示 | 3 件／60 分 |
| 急増の通知 | 1時間に N 件を超える通報で「通報急増」として優先表示 | 10 件 |
| AI 補助判定 | 有効／対象（NG要確認・通報あり・異常投稿）／月間上限／「非表示」判定を自動で反映するか | 無効 |
| シェア文 | X に投稿する文面のテンプレート（`{odai}` `{answer}` `{first}` `{url}` が使える。`{url}` は必須）とハッシュタグ | — |

## 困ったとき

- **開催者が「開催者ページに入れない」と言ってきた**：同じブラウザなら自動で入れる。別の端末なら合言葉で復旧できる（U-08）。合言葉を設定していない場合は、本人確認のしようがないので対応できない（A-03 で代理操作はできる）
- **結果ページが古い**：A-03 詳細の「ページキャッシュを再生成」
- **画像が出ない（OGP）**：A-08 で再生成。失敗するならフォントの設置
- **投稿できないという問い合わせ**：連続投稿の制限か、投稿停止（A-05 の「投稿元を制限」）の可能性。`restrictions` テーブルの `until` を過ぎれば解除される
