# 画面の記録（第4章 モックアップ）

画面デザインの原本は `docs/design/`（発注時のデザイン）。ここは、2026-10-22 の品質保証の作業で変えた画面を、**実装した画面そのもの**で撮ったもの（HTML/CSS は本体のコード）。

- 撮り方：ローカル（開発用データ）を Playwright の Chromium で表示。`sp-` は iPhone 13 の画面（390×844）、`pc-` は 1280×800
- 実機（iPhone Safari・Android Chrome）での表示は未確認（`docs/delivery/04_品質保証・テスト報告書.md`）
- OGP 画像は、撮った環境に日本語フォントがないので既定の画像になっている

| ファイル（`screens/` の `sp-`・`pc-`） | 画面・状態 | 関係する問題 |
|---|---|---|
| `u01-top` | U-01 通常（合言葉は必須、伏せ字＋「表示」） | BUG-006 |
| `u01-error-passphrase` | U-01 入力エラー（合言葉が短い）。理由が欄の下に出て、入力は残る | BUG-002 |
| `u01-top-with-hosted` | U-01「あなたが開催した大喜利」（このブラウザだけ） | BUG-005（D-02） |
| `u02-confirm` | U-02 開催確認 | |
| `u02-terms-sheet` | U-02 の上に重ねた利用規約のシート。閉じると U-02 に戻る | BUG-007 |
| `u03-created` | U-03 完了：X の募集ボタン＋ほかのアプリで共有 | BUG-003 |
| `u04-answer` | U-04 回答画面（訪問者） | |
| `u04-host-view` | U-04 を開催者本人が開いたとき：募集のシェアを出す | BUG-003 |
| `u06-answered` | U-06 回答完了（自分の回答のシェア＝「俺の回答」） | BUG-008 |
| `u07-list-new`・`u07-list-old` | U-07 みんなのボケ：新着順・古い順。データなしの状態は回答済みの人だけが開くので起きない | BUG-009 |
| `answer-link` | 回答のシェア URL を開いたところ | BUG-004 |
| `u08-host-empty` | U-08 開催者ページ：回答がまだない状態 | BUG-005 |
| `u08-recover` | U-08 別の端末から合言葉で開く | BUG-002 |
| `u10-result` | U-10 結果発表 | |
| `error-404` | 存在しない URL | BUG-004 |

ローディングの状態は、規約のシートを開いた直後の「読み込み中…」（通信が速いと一瞬）と、ボタンを押したあとの二度押し防止（押せない表示）だけ。
