# 0016 品質保証の続き（2026-10-24）で決めたこと

- 日付：2026-10-24
- 状態：採用（発注者の指示：指示書の反映の確認で見つかった不足を、二段階認証以外すべて進める）

## 決めたこと

1. **BUG-002 の合言葉は開催者用だけ（D-11）**。開催者ページ（開催した人の管理ページ）を開くための合言葉で、回答のときの合言葉は作らない（発注者に確認）。ADR 0015-3 の実装のまま
2. **Vercel の `vercel:prepare` は、MySQL 互換の DB では名前付きロック（`GET_LOCK`）で 1 つずつ動かす**。デプロイ直後に複数のインスタンスが同時に起き、DevSeeder が並行して流れて行が欠けたため（N-19）。SQLite はロックなし
3. **SEO**：`/robots.txt` と `/sitemap.xml` はサイトの URL（`app.baseURL`）から作る（静的ファイルだと Vercel と本番でドメインが違うときに直し忘れる）。robots.txt に管理画面のパスは書かない（推測しにくいパスにしているのに知らせてしまうため）。サイトマップは固定のページと、結果が出た大喜利（結果発表・結果未選出）の新しい 1000 件。募集中は 24 時間で終わるので載せない。全ページに canonical（`?page=` などを除いた URL）
4. **既定の OGP 画像は正式なもの**（`public/assets/img/ogp-default.png`、原本 `resources/og/ogp-default.html`）。URL に `?v=` を付けて差し替えを X などに伝える
5. **見た目の決まり**：利用者向けの画面では 12px 未満の文字を使わない（広告の「PR」表示だけ例外）。説明文の濃い灰は `--ink-body`（tokens.css）。「必須」の印は `.c-req`。ボタンと 1 行だけのリンクは 44px の高さ
6. **E2E に管理画面を足す**（`tests/e2e/specs/admin.spec.mjs`）。E2eSeeder の連続投稿の回数は、運用設定の上限内（100）にする

## 影響

- `public/robots.txt` を消した（`/robots.txt` は PHP が返す。Xserver も Vercel も、ファイルがなければ PHP に回る）
- 新しいルート：`GET /robots.txt`・`GET /sitemap.xml`
- マイグレーションなし
