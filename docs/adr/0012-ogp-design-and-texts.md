# 0012 OGP 画像の見た目を変え、文言と載せる順位を A-08 で編集できるようにする

- 日付：2026-10-21
- 状態：採用（Masato さんの依頼。ADR 0011 の結果用画像のレイアウトを置き換える）

## 決めたこと

1. **見た目**（ぼけばこが「お題に、みんながボケる場所」だと伝わるように）
   - 募集用：中央の白いカードにお題を大きく。背景に回答カードの一覧を描き、ぼかして薄く（不透明度 55%）重ねる
   - 回答シェア用：中央の山吹のカードに回答を大きく。上にお題、背景は募集用と同じ
   - 結果用：中央の山吹のカードに1位を大きく。その下の左に2位、右に3位（2位だけなら中央）。上にお題と判子、下にロゴと回答数
   - 文字は中央そろえ。行の長さをそろえ、最後の行に1〜2文字だけ落ちないようにする（少し小さくすれば1行に収まるなら小さくする）
2. **背景の回答カードには、本物の回答を載せない**（文字の形の線だけ）。募集用画像は開催時に作るので回答がまだなく、また回答前の人に回答を見せない（SPEC U-04）ため
3. **文言と載せる順位を A-08 で編集できる**（Masato さんの指定：「載せる順位」と「画像に載せる文言」）
   - 募集用の札（初期値「24時間限定 回答募集中」、16文字まで）
   - お題の前につける言葉（回答シェア用・結果用。初期値「お題：」、8文字まで、空でもよい）
   - 結果用の判子（初期値「結果発表」、6文字まで）、回答数（初期値「全{count}回答」、16文字まで、空なら出さない）
   - 結果用に載せる順位（1位だけ／1〜2位／1〜3位。初期値 1〜3位）
   - 値は settings テーブル（`ogp_*`）。A-10 の保存では触らない。変更は A-10 の変更履歴に残る
4. **プレビュー**：A-08 の各カードに、見本のお題・回答で実際に描いた PNG を出す（`GET /admin/ogp/preview/{kind}`）。描けない環境（Vercel の PHP には GD がない）では、同梱の見本画像 `public/assets/img/ogp-sample-*.png`（初期の文言で描いたもの）を出す

## 影響

- 文言を変えても作成済みの画像は変わらない。A-08 の「作り直しを予約する」で作り直す
- 見本画像は、レイアウトや初期の文言を変えたら作り直す（Noto Sans CJK Bold で描いた）
