# 0002 計測 API だけ CSRF の対象外にする

- 日付：2026-10-20
- 状態：採用

## 決めたこと

`POST /api/v1/events`（S-06 計測）だけ CSRF フィルタの対象外にする。他の POST（画面のフォーム、通報 API）はすべて CSRF の対象。

## 理由

計測はページ遷移を止めないよう `navigator.sendBeacon` で送る。sendBeacon は任意のヘッダーを付けられないため、CSRF トークンを送れない。

## 影響

- 計測 API は「イベント名と ID を記録するだけ」に限定し、何かを変更する処理を置かない
- 乱用対策はレート制限（匿名ブラウザID／IP 単位）で行う（工程4）
