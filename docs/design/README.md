# 画面デザイン（参照用）

このフォルダの `*.dc.html` は、デザインキャンバスで作った画面の原本です。**参照専用**で、そのままブラウザでは開けません（独自形式）。実装するときは次のように読みます。

- `<x-dc>` の中が画面のHTML。`style="..."` に色・余白・角丸・影の実値が入っている
- `{{...}}` はダミーデータの差し込み位置。`<sc-for>` は繰り返し、`<sc-if>` は条件分岐
- 末尾の `<script type="text/x-dc">` にダミーデータと画面内の状態遷移が書いてある
- 色・書体・角丸・影の正式な値は `Style.dc.html` と `CODING_RULES.md` 9-1 の `tokens.css`

| ファイル | 画面 |
|---|---|
| Main | U-01 トップ・開催 |
| U02〜U18 | ユーザー向け画面（U-02〜U-18） |
| A02〜A10 | 管理画面（A-02〜A-10）。A-01 ログインは最終工程で別途作成 |
| Style | スタイルガイド（トークン・部品） |

実装時は、このデザインを CodeIgniter の View と `public/assets/css` に書き起こします。`style` 属性と `<script>` をそのまま View に持ち込むことは禁止です（CODING_RULES.md 8-2）。
